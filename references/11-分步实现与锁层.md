# 分步实现与锁层：动作分三遍做，每遍量过就锁住

**为什么**：一份代码里同时改所有东西，返工时修好一项、别处就松一截。魔塔 MV 四轮实测：6.3 版画面满、动作慢；6.4 版快了、画面空；6.5 版镜头追上、安静镜头空；6.6 版安静镜头满了、高潮弱了——每次返工都顺手动了已经合格的部分（为了快删了碎片、为了不循环把飘尘也删了、为了画面满把主动作拖慢）。分三遍做、每遍锁住，后一遍只许往上加，不许删改前一遍。

## 1. 代码按层分开

| 层 | 放什么 | 文件（举例） |
|---|---|---|
| 第 1 层 · 主动作 | 共用事件表 `EVENTS`（每件事在哪一拍、是不是重击）+ 角色和道具的主动作 | `main.js` |
| 第 2 层 · 辅层 | 镜头缓推、跟摇（`push()`）；一层真的在走的粒子（`drift()`）；小东西小摆（`sway()`） | `aux.js` |
| 第 3 层 · 冲击 | 白闪、震屏、顿推、拟声大字、碎片火花、速度线——只给 `EVENTS` 里 `hit: true` 的事件加，时刻从事件表取，不另排 | `impact.js` |

- 模板 `templates/engine.html` 里有骨架：页面按 `?layers=1,2` 只画这几层（`LAYERS`），不带参数三层全开；`hits(t)` 给冲击层取刚发生的重击。
- 背景、角色造型这类静态画面放在别的文件（比如 `art.js`），不算动作层。
- 镜头也分层：缓推、跟摇在第 2 层，顿推、震屏在第 3 层（`cam.s = push(...) * (1 + (LAYERS.has(3) ? punch(...) : 0))`）。

## 2. 三遍

每一遍渲一版、量一遍，过线就锁。渲染出到这一遍自己的目录，帧不会混。

| 遍 | 做什么 | 渲 | 过线（MV 类） | 锁 |
|---|---|---|---|---|
| 第 1 遍 | 事件表、拍点、主动作速度（`beat()`、`drop()`、`travel()`、`perFrame()`） | `render.mjs index.html --layers 1 --out out/第1遍` | 动作最快 ≥ 650、一个动作 ≤ 0.5 秒、慢进慢出 ≤ 60%、画面在重播 ≤ 2%、动作有长有短 ≥ 0.6、一帧冲到全速 ≤ 35% | `lock.py lock --layer 1 --files main.js --motion qa_第1遍/motion.json` |
| 第 2 遍 | 每个镜头补至少 3 层辅动作，安静镜头三层托底 | `--layers 1,2 --out out/第2遍` | 辅层偏薄的镜头 ≤ 20%、成段全空的镜头 ≤ 10%、原地晃动 ≤ 15%、镜头在动 ≥ 35% | `--layer 2 --files aux.js --motion qa_第2遍/motion.json` |
| 第 3 遍 | 给重击加冲击叠层 | 三层全开 `--out out/第3遍` | 在动的面积 ≥ 16%、快动作 ≥ 170、空档 ≤ 15%、最长停顿 ≤ 0.5 秒，加上全部检查 | `--layer 3 --files impact.js --motion qa_第3遍/motion.json` |

量：`python3 <skill>/scripts/qa.py out/第1遍/<名字>.mp4 --out qa_第1遍 --style mv`（讲解片不加 `--style mv`）。**没过这一遍的线，`lock.py` 不让锁**（讲解片锁的时候加 `--style none`，只查通用的几项）；确实过不了，`--force --why "理由"` 强锁，理由写进锁文件和交付说明。看「动作快不快」以第 1 遍为准：三层合起来量时，辅层慢慢飘的粒子、缓推的镜头也会被算成动作，把全片的平均拉软——魔塔试跑里主动作层一个动作 0.23 秒、慢进慢出 13.5%，三层合起来变成 0.43 秒、46%。每一遍只看这一遍的那几项，别的项留给后面的遍。最后三层全开、合上声音出成片，照常跑 `qa.py` 和 `selfcheck.py`。

## 3. 锁住以后怎么返工

- `selfcheck.py` 的返工单每一行写着「属于哪层」。**只改当前这一遍的层。**
- 锁住的文件被改动，返工单第一行就报「锁层被改动」。
- 问题确实出在已经锁住的层：明说「解锁第 X 层」，改完从第 X 遍重新渲、重新量，再 `lock.py lock --layer X` 重新锁；X 之后的各遍也重渲、重量、重锁。
- 重新锁时数字比上次退步一成以上，`lock.py` 会拒绝——这次改动挤掉了这一层：退回去，换一种不伤它的改法。确实要接受，加 `--force --why "理由"`，理由写进交付说明。
- 每遍最多返工 3 轮；交付说明里写清每遍锁住时的数字、解过几次锁、为什么。

## 4. 时间

一遍多一次渲染和测量：18 秒的片段每遍两三分钟，60 秒的片子每遍六七分钟（渲染可以只渲有问题的段，`--from/--to`）。省时间的办法：第 1、2 遍先在 4 秒小样上过一遍，再上全片。
