# 运动与镜头：让画面「有重量、有节奏」

成片像「AI 做的 PPT」，几乎都是因为：所有东西共用一条时间函数、匀速滑动、同时淡入、机位不动。

## 1. 分镜：每个镜头一个主任务

`docs/分镜.md` 里每个镜头写一行：

| 镜头 | 起–止（秒） | 对应 | 主任务（观众此刻看什么） | 主体 / 次主体 / 背景 | 进场 → 动作 → 出场 | 相机 | 声音事件 |
|---|---|---|---|---|---|---|---|
| s3 | 8.0–11.2 | 第 5–8 拍 / 旁白第 3 句 | 猫第一次挡在勇士前面 | 猫 / 勇士 / 塔内火把 | 猫从右侧跃入 → 举剑格挡 → 勇士回头看它 | 慢推 + 格挡时轻震 | 格挡「锵」打在第 7 拍 |

- 一个镜头 1.5–5 秒，越到高潮越短；讲解片按旁白的句子切。
- 同一时刻只有一个主事件，其他元素给它让路。
- 全片的节奏曲线：开头 2 秒有钩子 → 发展 → 高潮（音乐高潮或故事反转）→ 收束（落版停 1.5 秒以上）。

## 1b. 景别、角度和构图（分镜表里每个镜头都要写景别）

| 景别 | 画面里有什么 | 用在哪 |
|---|---|---|
| 大特写 | 一只眼睛、一只爪子、一行关键数字、杯沿 | 钩子、紧张、高潮前一拍 |
| 特写 | 一张脸、一个物体占满画面 | 情绪、强调、结果 |
| 中景 | 角色上半身或一组物体 | 动作、对话、演示 |
| 全景 | 角色全身 + 环境 | 交代空间、行动开始 |
| 远景 / 鸟瞰 | 整个场景、地图全图 | 开场、转场、收尾 |

- 全片至少用 4 种景别，相邻两个镜头景别不同；节奏越紧，景别跳得越大（全景 → 大特写）。
- 角度至少 2 种以上：平视、俯拍、低角度仰拍、过肩、主观视角。
- **主体至少占画面高度的 1/3**；特写就让它占满。空底上摆一个小图，是最常见的失败构图。
- 画面铺满：背景是场景（墙、桌面、天空、地形、纹理），不是纯色空底；纯色大底只在动态排版的快切里用。
- 三分法：主体放在三分线上，视线方向留出空间；文字和主体分开在两边，别叠在一起。
- 讲解片别用「左文右图」的固定版式：每个要点换一种构图（全景演示 → 特写细节 → 俯拍全貌）。

## 2. 运动语言

一个完整动作：**预备 → 加速（拉伸）→ 冲击 → 压扁 / 过冲 → 回稳 → 余波**。

- 预备：反方向蓄力 3–6 帧（下蹲、后拉）。
- 冲击：速度最快的一刻可以拉长 5–15%；撞上的那一帧压扁，再弹回。
- 过冲：到达目标后冲过一点再回来，用阻尼弹簧做（`spring(tau, f, z)`，z 取 0.4–0.7），不要匀速直线。
- 余波：冲击传到周围，周围元素晚 2–4 帧轻轻一抖（不要整个画面一起抖）。
- 形变要有原因：压扁、拉伸来自速度和冲击，不要随手加缓动。

## 3. 错相和层次

- 主体先动 → 次层晚 2–4 帧 → 相机晚几帧 → 阴影和文字更晚。
- 多个元素依次入场（每个错开 40–100 毫秒），不要同时出现；但整体要汇成一个节奏（比如都落在同一拍之前）。
- 前景偶尔掠过画面（树枝、云、纸片）补层次；远景缓慢漂移，制造视差。
- 背景不要是静止图：慢速流动的纹理、漂浮的粒子、缓慢变化的光。

## 4. 相机

- 一个容器做相机：`translate + scale + rotate`，关键帧 `[t, 缩放, x, y]`，缩放按对数插值（`exp(lerp(log(a), log(b), p))`），推拉才匀称。
- 每个镜头至少有一种相机运动：慢推（铺垫）、快推（强调）、横摇（展示）、环绕（三维）、跟拍（角色移动）。
- 卡点片：每拍一个很小的推进脉冲（+1–1.5% 缩放，指数衰减），高潮后加大。
- 不要推完马上拉回来，不要所有镜头都同一种推法。

## 5. 转场（准备 4–5 种轮换用，别全片只有一种）

| 转场 | 做法 | 适合 |
|---|---|---|
| 形状接形状 | 上一镜的某个形状（圆、气泡、徽章）放大铺满，成为下一镜的底 | 品牌片、信息图 |
| 颜色铺满 | 从某个物体扩出一个圆，0.3 秒内铺满最远的角，再收进下一镜的物体 | 卡点片高潮 |
| 甩镜头 | 快速横移 + 运动模糊，下一镜从反方向甩进来 | 动作、紧张段 |
| 遮罩擦除 | 撕纸边、墨迹、地图卷轴、百叶窗擦过去 | 绘本、国风、地图 |
| 物体穿过镜头 | 前景物体（积木、云、鸟群）飞过挡住画面，过去后已经换景 | 科普、绘本 |
| 匹配剪辑 | 上下两镜的主体在同一位置、同一形状 | 叙事片 |
| 硬切 | 只在节拍上用，并配一个冲击（缩放弹跳、闪一下颜色） | 卡点段 |

**闪白**只能偶尔用一次，不能拿来遮转场。

## 6. 文字动画

- 逐词遮罩升起，每词错开 40–60 毫秒，带一点旋转（1–2°）回正。
- 重点词：换色、加粗、下划线画出来，或晚 0.1 秒单独砸下。
- 退场比进场快（进 0.4–0.6 秒，出 0.2–0.3 秒）。
- 字停的时候也别完全死：极慢的漂移或轻微缩放（1% 以内）。

## 7. 翻车信号（静帧和成片自查时专门找这些）

- 所有图层共用一个进度（同步感极强）。
- 匀速直线移动、线性缩放。
- 一个画面停着不动超过 1.5 秒（片尾定格除外）。
- 镜头之间只有淡入淡出。
- 字还没读完就切走；两句大字叠在一起。
- 高潮没有落在音乐高潮上。
