# 运动与镜头：让画面「有重量、有节奏」

成片像「AI 做的 PPT」，几乎都是因为：所有东西共用一条时间函数、匀速滑动、同时淡入、机位不动。

反过来也会翻车，而且静帧上看不出来：动作拖到 1 秒多、两头对称地慢进慢出、每个镜头从头慢推到尾、满屏原地晃——动起来软、飘、没劲。逐帧量过（科学讲解那条）：Opus 5.5 原片一个动作 0.33 秒做完，最快时每秒 963 像素，最快的一刻在动作的前 1/4；GPT-6 带旧版 skill 是 1.13 秒、每秒 219 像素、最快的一刻在正中间，镜头 100% 的时间在推。

## 1. 分镜：每个镜头一个主任务

`docs/分镜.md` 里每个镜头写一行：

| 镜头 | 起–止（秒） | 对应 | 主任务（观众此刻看什么） | 主体 / 次主体 / 背景 | 进场 → 动作 → 出场 | 相机 | 声音事件 |
|---|---|---|---|---|---|---|---|
| s3 | 8.0–11.2 | 第 5–8 拍 / 旁白第 3 句 | 猫第一次挡在勇士前面 | 猫 / 勇士 / 塔内火把 | 猫从右侧跃入 → 举剑格挡 → 勇士回头看它 | 先不动，格挡那一拍快推 + 轻震，推完停住 | 格挡「锵」打在第 7 拍 |

- 一个镜头 1.5–5 秒，越到高潮越短；讲解片按旁白的句子切。
- 同一时刻只有一个主事件，其他元素给它让路。
- 「进场 → 动作 → 出场」一栏写**这个镜头自己的事**，落到拍点上。魔塔 MV 实测：GPT-6 的分镜表 31 个镜头里 25 个这一栏是同一句话（「主角预备 0.1 秒 → 冲出 → 剑风错开；相机两拍之间推进，再停」），做出来就是每个镜头同一套循环。
- 全片的节奏曲线：开头 2 秒有钩子 → 发展 → 高潮（音乐高潮或故事反转）→ 收束（落版停 1.5 秒以上）。

## 1b. 景别、角度和构图（分镜表里每个镜头都要写景别）

| 景别 | 画面里有什么 | 用在哪 |
|---|---|---|
| 大特写 | 一只眼睛、一只爪子、一行关键数字、杯沿 | 钩子、紧张、高潮前一拍 |
| 特写 | 一张脸、一个物体占满画面 | 情绪、强调、结果 |
| 中景 | 角色上半身或一组物体 | 动作、对话、演示 |
| 全景 | 角色全身 + 环境 | 交代空间、行动开始 |
| 远景 / 鸟瞰 | 整个场景、地图全图 | 开场、转场、收尾 |

- 全片至少用 4 种景别，相邻两个镜头景别不同；节奏越紧，景别跳得越大（全景 → 大特写）。
- 角度至少 2 种以上：平视、俯拍、低角度仰拍、过肩、主观视角。
- **主体至少占画面高度的 1/3**；特写就让它占满。空底上摆一个小图，是最常见的失败构图。
- 画面铺满：背景是场景（墙、桌面、天空、地形、纹理），不是纯色空底；纯色大底只在动态排版的快切里用。
- 三分法：主体放在三分线上，视线方向留出空间；文字和主体分开在两边，别叠在一起。
- 讲解片别用「左文右图」的固定版式：每个要点换一种构图（全景演示 → 特写细节 → 俯拍全貌）。

## 2. 运动语言

一个完整动作：**预备 → 加速（拉伸）→ 冲击 → 压扁 / 过冲 → 回稳 → 余波**。

- 预备：反方向蓄力 3–6 帧（下蹲、后拉）。
- 冲击：速度最快的一刻可以拉长 5–15%；撞上的那一帧压扁，再弹回。
- 过冲：到达目标后冲过一点再回来，用阻尼弹簧做（`spring(tau, f, z)`，z 取 0.4–0.7），不要匀速直线。
- 余波：冲击传到周围，周围元素晚 2–4 帧轻轻一抖（不要整个画面一起抖）。
- 形变要有原因：压扁、拉伸来自速度和冲击，不要随手加缓动。

**时长和曲线（硬指标，`qa.py` 动态检查会量）**

**Opus 5.5 的运动词汇**（读了它写的几百个动画文件总结的；参数是它代码里的原值；模板里都有现成函数）

| 动作 | 速度怎么走 | 参数 | 模板函数 |
|---|---|---|---|
| 入场、到位 | 预备（先反向退一点）→ 先快后慢冲过去 → 冲过头、来回弹两三下稳住 | 预备 0.1 秒、退 5%（或 8 像素、缩 3%）；主动作 0.3 秒 outCubic；冲过头 3%–10%，2.4–3.2 赫兹，衰减 5.5–9 /秒 | `beat()` |
| 砸下、落地、离场 | 先慢后快，**终点最快、到点急停** | 0.1–0.13 秒（3–4 帧）inCubic；落地压扁 5%–16%，0.05 秒指数弹回 | `drop()`、`squash()` |
| 冲击（出拳、亮相、砸地） | 三件套 | 白闪 1–3 帧、震屏 3–8 帧（隔帧反向、平方衰减）、镜头顿推 4%–10% 在 0.2 秒内回来 | `flash()`、`shake()`、`punch()` |
| 轻的小东西弹出 | 先快后慢带一点过冲 | 0.2–0.3 秒 outBack | `pop()` |
| 大东西走位 | 先快后慢 | 0.5–0.7 秒 outQuart | `travel()` |
| 一组东西 | 错开很小，像一阵浪 | 1–2 帧（0.03–0.06 秒）；逐字不超过 0.04 秒；发牌这类才 0.12–0.24 秒 | `after()` |
| 同一个东西的几个属性 | 各有起点和曲线 | 位置先走，大小晚 0.06 秒，旋转再晚一点 | 手写偏移 |
| 原地小晃 | 只当底噪 | 1–3 像素、缩放 1%–4%，周期 1.2–3.4 秒；很多绑在拍点上 | `Math.sin` |
| 镜头 | 短促顿推再回、推完停；慢推用匀速 | 顿推 0.2–0.35 秒推近 4%–10%；完全静止最多 8 帧、只在卡点 | `punch()`、`cameraAt()` |

**动作要有长有短**：一条片子里砸下只有 3–4 帧、入场 0.3 秒、大东西 0.5–0.7 秒，自然就有了「加速度、速率曲线有变化」。所有动作同一个时长、同一条曲线（比如全是 0.42 秒的 outQuart），快是快了，看着机械。

| 项 | 要求 | 做法 |
|---|---|---|
| 一个动作用时 | 快剪、MV 档多数 0.25–0.5 秒，按动作类型拉开（见上表）；超过 0.6 秒只给大东西走位、镜头运动和刻意的慢动作。讲述铺陈档的稳动作（照片慢推、路线一笔画出来、零件滑入）0.5–1.0 秒，穿插 0.25–0.4 秒的弹出、落定 | `beat()`、`drop()`、`pop()`、`travel()` |
| 速度曲线 | 快起慢停：最快的一刻在动作前 1/3，后面是一条长尾巴慢慢落定，可以带一点回弹 | `E.outQuart`、`E.outExpo`、`E.outBack`、弹簧 f 2.5–4 / z 0.5–0.7 |
| 不要用 | 两头对称的慢进慢出（`inOutCubic`）做物体动作；匀速（linear）；弹簧频率低于 2（软） | 对称缓动只给镜头推拉 |
| 动作幅度 | 主要动作挪动画面宽度的 15% 以上；最快时每秒 650 像素以上（快剪、MV 档）、250 像素以上（讲述档的稳动作），1920 宽 | 从画外飞入、跨过半个画面落位 |
| 节奏 | 按节奏档（SKILL.md 第 14 条）：讲述、快剪档动—停—动，一个点讲完、一下利落的动作做完停 0.3–0.8 秒（停顿占 15%–65% / 15%–35%）；MV 档动作之间最多停 0.2 秒、停顿不超过 15% | 关键帧之间按档留停顿 |

## 2b. 按事件写，不按周期写（MV、打斗、卡点段最容易犯）

要求「热闹」「镜头多动」之后，GPT-6 的典型写法是把动作写成周期函数，每拍重播一遍：

```js
// GPT-6 魔塔 MV（第 6.2 版）：挥剑、魔王扇翅、刀光、镜头顿推和震屏，全按 0.78 秒一圈循环
let q = (((time - 33) % 0.7792) + 0.7792) % 0.7792;
return beat(q, 0.06, { dur: 0.23 }) - drop(q, 0.59);
```

量出来镜头在动、空档少、在动的面积够，门槛都过；看起来是一道刀光在原地连播三遍，像节拍器。Opus 5.5 原片同一段的写法：

```js
// Opus 5.5 魔塔原片：每件事钉在具体的小节和拍上，只发生一次
const b1 = ev(27, 1), b2 = ev(27, 2), b3 = ev(27, 3);   // 第 27 小节第 1、2、3 拍
if (t < b2) { /* 冲刺：残影 + 速度线 + 尘土，震屏 24 */ }
else        { /* 双剑相交「锵！」+ 闪白，震屏 34；第 3 拍起白场越来越亮 */ }
// 下一小节：一帧反色 → 白场里劈下 → 满屏 X 斩痕「斩！」，震屏 40 → 56
const SWING = [0, 0.08, 0.18, 0.3, 0.62, 1];   // 劈下的逐帧进度：前 3 帧慢、后 2 帧快
```

- **每件事只发生一次，钉在拍点上**：用模板的 `ev(小节, 拍)` 算时刻；`if (t < 下一拍)` 分段，或写成事件表 `[{at: ev(27, 1), ...}, ...]`。
- **高潮每 2.4 秒至少 5 件不同的事**：原片这 2.4 秒是剑上爆出闪电 → 勇士带残影冲刺 → 闪白「锵！」双剑相交 → 白场越来越亮 → 一帧反色 → 满屏 X 斩痕「斩！」。「眩晕」原片同样 2.4 秒也有七八件事。
- **同一类冲击一次比一次狠**：`ramp(i, 起, 止, 次数)`——震屏 24 → 34 → 40 → 56、红蓝错位 8 → 10 → 14 → 16，越到高潮越重。每次都一样的力度就是节拍器。
- **事件密，每件事也要快**：一件事 0.2–0.35 秒做完（砸下 3–4 帧、刀光 5–6 帧、入场 `beat()` 0.3 秒），做完立刻接下一件；对峙、角力这类定格最多 4–6 帧。魔塔第 6.3 版把高潮写成了一串不同的事，单个动作却拖到 0.5 秒（原片 0.3 秒），中间角力停了 0.6 秒，冲击感反而弱了。
- **冲击叠层，快和热闹一起要**：重击那一帧同时爆开一组层——白闪 1–3 帧（`flash()`）、震屏（`shake()`）、镜头顿推（`punch()`）、红蓝错位、拟声大字（`sfx()`：「锵！」「斩！」「轰！」，带描边、轻旋转，砸进来 0.1 秒、停 0.3–0.5 秒再淡出）、一圈碎片火花（`burst()`：先快后慢飞远、带重力下落）、速度线。主动作只要三四帧，画面的热闹来自这些同时炸开、各自飞走的伴奏层，所以动作快和画面满不打架。魔塔 6.3 版碎片火花多、动作慢（0.5 秒）；6.4 版动作快了（每秒 999 像素），伴奏层却没了，在动的面积从 21% 掉到 15%。Opus 魔塔原片两段打斗里用了 13 次（锵、铛、轰、唰、砰、斩、破防……）。
- **关键动作逐帧写加速**：`perFrame(t, 起点, [0, .08, .18, .3, .62, 1])`，蓄力几帧、爆发几帧，你写多少就是多少。
- **相邻两拍不演同一个动作**：这一拍冲刺，下一拍相交，再下一拍蓄力；要重复（比如连砍三刀）就让每刀的方向、景别、力度不一样。
- **`t % 周期` 只给背景小效果**：眨眼、冒汗、火星和气泡上飘、速度线闪动、滚动的背景可以循环。Opus 魔塔原片 1.4 万行代码里有十来处取余，全是这类；主角动作没有一处。
- `selfcheck.py` 会逐个镜头查「画面在重播」：扣掉镜头运动之后，同一个镜头里隔固定时间画面又回到原样，就是在重播。

## 2c. 主辅分工：每个镜头 1 个快主动作 + 至少 3 层辅动作

来自《七层动效手册》（从 MiniMax H3 产品片案例反推的动效法则）第 02 节：混乱来自同一层里有多个变量抢注意力，单调来自同时在动的层数不够——所以同一时刻只放 **1 个主动作**（大幅、有起有停、要被看懂），再配 **2–4 个辅动作**（小幅、可以循环、不抢注意力）。画面满而不乱，靠的是辅层。

按这个分法量了魔塔 MV（每帧：主动作 = 明显动作面积 ≥ 2%；辅动作 = 镜头在动、额外的快东西、原地小幅循环三层里有几层）：

| | 辅层偏薄的镜头（每帧平均不到 2 层） | 有成段全空的镜头（一成以上的帧什么都没动） |
|---|---|---|
| 魔塔原片 · 「眩晕」原片 | 8% · 17% | 0% · 0% |
| GPT-6 魔塔 6.2 版（主动作在循环） | 3% | 0% |
| 6.3 版（按事件写） | 32% | 29% |
| 6.4 版（每件事要快） | 83% | 33% |
| 6.5 版（冲击叠层） | 29% | 36% |

- **差距在安静镜头，不在高潮**：高潮段各版辅层都够；分食、包扎、对话这类镜头，原片照样有镜头缓推、飘落的灰、烛火在托着，GPT-6 的是一张不动的画。
- **主动作不许循环，辅层可以**：6.2 版的飘尘、怪物群、火星本来就是合格的辅层，毛病只在主动作也在循环；6.3 教「按事件写」时 GPT-6 把辅层的小循环也删了，安静镜头才开始空。
- **安静镜头的三层托底**：镜头匀速缓推（`push()`）+ 一层真的在走的粒子（`drift()`：飘落的灰、上升的火星、雨丝）+ 一两样小东西小摆（`sway()`：烛火、斗篷角、旗子，幅度 1–3 像素，各自错开）。辅层要小、小面积，别让整排怪物一起上下晃（那会算成原地晃动，超过 15% 报警）。
- **节奏局部可预测、整体猜不到**（手册第 05 节）：速度斜坡（半秒内从几乎静止加速到极快）、假定格（画面定住三分之一秒，随即被下一个镜头打断）、镜头长度不等。规则拍一出现，观众就猜到了。

`qa.py` / `selfcheck.py` 加 `--style mv` 会按镜头查这两项。

## 3. 错相和层次

- 主体先动 → 次层晚 2–4 帧 → 相机晚几帧 → 阴影和文字更晚。
- 多个元素依次入场（每个错开 40–100 毫秒），不要同时出现；但整体要汇成一个节奏（比如都落在同一拍之前）。
- 前景偶尔掠过画面（树枝、云、纸片）补层次。
- **同屏至少 3 样东西在演**：主动作 + 跟随动作 + 一串依次飞入、拼装、跳动的小物件（用 `after(t, start, i, 0.06)` 错开）。原片的热闹是这样来的：论文碎成一串小方块飞出去、零件一个个拼起来、人物跳过一排字块——都是从 A 到 B 的动作。
- 背景可以有极轻的底噪（流动的纹理、几颗漂浮的粒子，幅度不超过画面高度的 1%），但**不能拿原地晃充当动作**：方块上下浮、人物微微起伏、粒子漂，镜头里没有一样东西真的去了别处，就是「在晃、没在演」。

## 4. 相机

- 一个容器做相机：`translate + scale + rotate`，关键帧 `[t, 缩放, x, y]`，缩放按对数插值（`exp(lerp(log(a), log(b), p))`），推拉才匀称。
- **镜头运动要有起有停**：推、摇、环绕、跟拍都用缓入缓出，推完停住，让动作在静止的镜头里发生。每个镜头从头慢推到尾，是最常见的「飘」。镜头在动的时间一般不超过全片一半；照片素材的推镜头可以多一些，但照片上必须叠着在动的东西。
- 镜头运动的用处：快推（强调、砸下）、横摇（展示）、环绕（三维）、跟拍（角色移动）、慢推（只在铺垫段，推完要停）。
- 卡点片：每拍一个很小的推进脉冲（+1–1.5% 缩放，指数衰减），高潮后加大。
- 不要推完马上拉回来，不要所有镜头都同一种推法。

## 5. 转场（准备 4–5 种轮换用，别全片只有一种）

| 转场 | 做法 | 适合 |
|---|---|---|
| 形状接形状 | 上一镜的某个形状（圆、气泡、徽章）放大铺满，成为下一镜的底 | 品牌片、信息图 |
| 颜色铺满 | 从某个物体扩出一个圆，0.3 秒内铺满最远的角，再收进下一镜的物体 | 卡点片高潮 |
| 甩镜头 | 快速横移 + 运动模糊，下一镜从反方向甩进来 | 动作、紧张段 |
| 遮罩擦除 | 撕纸边、墨迹、地图卷轴、百叶窗擦过去 | 绘本、国风、地图 |
| 物体穿过镜头 | 前景物体（积木、云、鸟群）飞过挡住画面，过去后已经换景 | 科普、绘本 |
| 匹配剪辑 | 上下两镜的主体在同一位置、同一形状 | 叙事片 |
| 硬切 | 只在节拍上用，并配一个冲击（缩放弹跳、闪一下颜色） | 卡点段 |

**闪白**只能偶尔用一次，不能拿来遮转场。

## 6. 文字动画

- 逐词遮罩升起，每词错开 40–60 毫秒，带一点旋转（1–2°）回正。
- 重点词：换色、加粗、下划线画出来，或晚 0.1 秒单独砸下。
- 退场比进场快（进 0.4–0.6 秒，出 0.2–0.3 秒）。
- 字停的时候也别完全死：极慢的漂移或轻微缩放（1% 以内）。

## 7. 翻车信号（静帧和成片自查时专门找这些）

- 所有图层共用一个进度（同步感极强）。
- 匀速直线移动、线性缩放。
- 动作拖到 1 秒以上、两头对称慢进慢出（静帧看不出，动起来软、飘）。
- 每个镜头从头推到尾；镜头一直在动。
- 画面只有原地晃（漂浮、上下浮动、微微起伏），没有东西从 A 到 B。
- 同一时刻只有一样东西在动，其余全静止。
- 同一个动作每拍重播一遍（`t % 周期` 写的主动作）；每次冲击一样重。
- 一个画面停着不动超过 1.5 秒（片尾定格除外）。
- 镜头之间只有淡入淡出。
- 字还没读完就切走；两句大字叠在一起。
- 高潮没有落在音乐高潮上。
