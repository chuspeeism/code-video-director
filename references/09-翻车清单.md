# 翻车清单：模型默认会做偏的地方

动手前过一遍，交付前再过一遍。每条都是真实做片时被要求返工的地方，写法是「默认会怎么做 → 应该怎么做」。

## A. 通用（多个模型、多条片子反复出现）

| # | 默认会怎么做 | 应该怎么做 |
|---|---|---|
| 1 | 风格没落实，画面退回「居中大字 + 渐变底 + 全体淡入」，或米白底、细黑线、等宽小字 | 风格翻译成元素清单，每帧都要有；静帧缩小到 360 宽还能认出风格 |
| 2 | 人物、知名角色用代码画成简陋的平面图形，像不像、精不精细都不到位 | 精细人物优先三维（现成模型）或生图；必须纯代码时，把功夫花在造型统一和质感层 |
| 3 | 元素都摆上了，最要紧的那个意思却没让人一眼感到 | 导演单写清「观众必须感到的那一件事」，安排一个镜头专门把它演出来 |
| 4 | 为了卡点越切越快，字幕读不完、剧情看不懂 | 讲故事时可读性优先；字幕停留 ≥ 字数 × 0.25 秒 + 0.5 秒 |
| 5 | 机位不动，转场只会硬切加闪白 | 每个镜头至少一种相机运动；准备 4–5 种转场轮换 |
| 6 | 把举例清单当上限：说「几种怪物」就只画三种，感情线点到为止 | 用户说「多」「要足」，就按 2–3 倍去做；感情线给足镜头时长 |
| 7 | 题材和主角换成自己熟悉的梗（自家 IP、AI 圈的梗） | 用户给的题材、主角原样用 |
| 8 | 创意保守，一个套路用到底，结尾只是定住 | 每隔几秒来一个没想到的；结尾有收束或反转 |
| 9 | 两个要求冲突时偏向稳妥、合规格 | 偏向观感和用户点名的要求，在交付说明里写清取舍 |
| 10 | 提示词里一出现「用代码做」「宣传」，就在画面上加「代码生成」角标、代码浮窗 | 不加任何自证元素 |
| 11 | 用户点名的歌、配音服务、工具被悄悄换掉（比如自己合成一段「类似的」配乐） | 点名的东西必须照用；实在拿不到，交付说明里写明原因和替代品 |
| 12 | 卡通渲染的三维被做成二维平面，角色一转身就穿帮 | 角色要转角度，就用真三维 |
| 13 | 「不要配乐」的片子还是垫了一层底噪或音乐 | 句间真静音，qa.py 会查 |
| 14 | 讲解片编造数字、论文、日期 | 查证；查不到标「示意」或不写 |

## B. GPT-6（Codex）实测（训练中持续补充）

| # | 默认会怎么做 | 应该怎么做 |
|---|---|---|
| B1 | 把片子做成网页信息图 / 幻灯片：每个镜头同一个版式（左上标题、中间一张线条图、四周小标签、底部字幕条），带页码、页眉、日期戳；底子是平的，没有纹理、光影和布景 | 每个镜头是一个铺满的场景，有布景、道具、光和纹理；构图轮换；去掉页码、页眉这类界面装饰；小字标签只留关键的 |
| B2 | 用户点名的画面类型被偷换：要「现场复原图」给一张真实照片，要「山形地势图」给一条色带 | 点名的画面类型逐个画出来，写进导演单硬要求表，静帧自查时逐个找 |
| B3 | 同一张底图（地图、界面）反复出现，机位和焦点不变，看起来在原地踏步 | 同一底图再出现时必须换景别（全景 → 局部特写）、换焦点、换光 |
| B4 | 生图做素材时，每张都是同一个构图（同一张桌子、同一个机位、中景），只换主角姿势，像同一个监控画面 | 先列分镜表定好每张的景别和角度（大特写、低角度、俯拍、过肩、慢镜特写），再写生图提示词；参考图只管主角长相 |
| B5 | 要求「画面切换卡在节拍上」，却 20 秒只切 2 刀，靠叠化慢慢过渡 | 卡点片高能段每 1–2 拍硬切一刀并加冲击；20 秒至少 10 刀；qa.py 看切点数和落拍比例 |
| B6 | 讲解片做成仪表盘：左边大数字 + 小字引用，右边一个小小的静态场景，标签页导航在角上 | 每个要点让角色做一个动作把道理演出来；主体放大到占画面 1/3 以上；去掉界面装饰 |
| B7 | 主体太小、留白太大、颜色发淡、对比度低 | 主体至少占画面高度 1/3；画面铺满场景；颜色按风格给足 |
| B8 | 「砸几句大字」做成左下角的小字淡入 | 大字宽度至少占画面 1/3，放大回弹砸进来，配一个重拍 |
| B10 | 三维模型网站要登录才能下载时，申请控制用户的主力浏览器去登录下载，任务卡在授权弹窗上二十多分钟 | 只用不登录就能直接下载的免费模型；拿不到就用 Blender 几何体搭简化造型，写进交付说明 |
| B11 | 带了 skill 后版面不再像网页，但等轴插画仍然是「画面中央一座浅色孤岛平台」，四周大片空蓝，小人很小 | 积木世界铺到画面边缘，镜头推近角色，颜色提亮；qa.py「画面空不空」必须过 |
| B12 | 地图纪录片的地图段每次都是同一个景别的平面地图，没有桌面布景和光影 | 先做桌面布景（木纹、灯光、折痕、红铅笔、印章）；回到地图就换景别；地势打侧光或立成沙盘 |
| B13 | 任务里给了配音用的 Gemini 密钥，它顺手拿这把密钥去调 Gemini 生图做复原场景 | 密钥只用在用户说的用途上；生图用自己带的生图能力 |
| B14 | Blender 做的片子全程一个正面固定机位，只变颜色或换角色，看起来和平面插画一样（二十四节气 30 秒相邻相似度 0.99） | 每个镜头换机位、镜头里有运动（推、摇、绕、低角度），用前景和视差体现三维 |
| B15 | 导入的现成模型直接摆在画面中央：T 型姿势、自带材质（不是卡通渲染）、名字用普通小字 | 摆姿势或用自带动作；材质换成卡通材质加描边；角色名做成大字标题卡，高潮叠速度线、光爆 |
| B9 | 高潮（摔碎、反转、亮相）一闪而过，没有特写 | 高潮给大特写 + 慢放或定格 + 最重的那一拍，前面留一拍安静做铺垫 |

**做对了的（保持）**：实现路线选得对（该生图就生图、该纯代码就纯代码）；生图的主角前后一致；「不要配乐」时句间是真静音；规格、时长准确。

## C. 流程类（影响能不能一次做完）

- 网络断、工具装不上时卡住不动：先换镜像或换方案（系统 Chrome 代替下载浏览器、系统语音代替在线配音），记下来继续做。
- 一口气写完所有代码才第一次渲染，发现跑不起来：第 2 步就要渲出第一帧。
- 全片渲染中途被打断从头再来：render.mjs 会跳过已渲好的帧，直接重跑。
- 画风没出样张就往下做，最后整体返工：第 6 步静帧自查不能省。
