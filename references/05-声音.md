# 声音：配乐、卡点、旁白、音效、混音

**声音先行**：先把声音定下来、量出时间，再排画面。画面跟声音走，片子才有「对上了」的感觉。

## 1. 配乐从哪来（按优先级）

1. **用户给的歌**：必须用，不许换，不许用代码合成一段「类似的」替代。只给了歌名、没给文件时，先找官方或授权的公开来源；拿不到就在交付说明里写清楚，并用风格接近的免费可商用曲子顶上。
2. **免费可商用曲库**（用户没指定歌时首选）：如 Mixkit、Pixabay Music 等明确允许免费商用的曲库。记下曲名、作者、链接、授权，写进交付说明。
3. **代码合成**（没网、找不到合适的曲子、或用户要求时）：按第 5 节的做法做，别做成单薄的「嘀嘀」声。

用户说「不要配乐」：音轨里除了旁白（和必要的音效）什么都没有，句与句之间是**真静音**。

## 2. 卡点（用户说卡点、踩拍、跟着节拍切时）

1. `python3 <skill>/scripts/beats.py 歌.mp3 --json docs/节拍.json`，拿到 BPM、拍点、小节重拍、高潮候选、安静段和响亮段。
2. **不要只信自动拍点网格**，它常常整体偏一两拍。高潮点以低频能量跳升的位置为准；必要时在跳升点附近按 20 毫秒窗口再看一遍。
3. **截哪一段**：按导演单要的情绪截（如「主歌安静铺垫 → 副歌爆发」），起点放在一个小节的开头。把**最重要的画面**（反转、变身、产品亮相、logo）对准高潮点：`歌曲起点 = 高潮在歌里的时间 − 高潮在片里的时间`。
4. **排镜头**：镜头切换放在拍点上，重动作（落地、撞击、亮相、大字砸下）放在小节重拍上。安静段每 2–4 拍切一次或不切，爆发段可以每拍一切，但**字要读得完的地方不许为了卡点切太快**。
5. 片尾收在一个乐句的结尾，音乐最后 1–2 秒淡出，别突然断掉。
6. 交付前用 `qa.py --music` 看「切点落在拍点 ±80 毫秒内的比例」，要明显高于随机落点的比例。

## 3. 旁白（有配音时）

1. **先写稿**：按导演单的内容核心写，口语化，每句不超过 20 个字（也是一条字幕）。60 秒旁白中文约 220–260 字；30 秒约 110–130 字。
2. **选声音**：用户点名的服务就用它（比如 Gemini、OpenAI 等的语音合成），用户给了脚本或密钥就用给的；都没有时，用系统自带语音兜底（macOS `say -v '?'` 列出声音），并在交付说明里写明。浑厚男声挑低沉成熟的音色，清亮女声挑明亮年轻的音色；先用同一句话试两三个候选，挑一个。语气写一句短的风格提示（如「沉稳的纪录片讲述」「轻快清楚的科普讲解」）。
3. **逐句合成**，每句一个文件，用 ffprobe 量时长；句间留 0.25–0.4 秒，段落之间留 0.6–0.8 秒。把每句的起止时间写进 `timeline.json`，这就是全片的时间骨架。
4. **画面跟着旁白走**：说到哪个词，那个东西正好出现或被点亮；换场景放在一句开口之前 0.1–0.2 秒。
5. **字幕**：每句旁白一条字幕，开始和结束时间等于这句话的起止，字和念的完全一致。
6. 密钥只从环境变量或系统钥匙串读，不写进代码、不打印、不放进交付文件。

## 4. 音效

- 只在「事件」上放：落地、碰撞、切换、打字、点击、碎裂、大字砸下。不是每个动作都要。
- **对准峰值**：音效文件的最响点（|样本|最大处）对准画面里接触的那一帧，而不是让文件开头对准。
- 微错开更自然：预备音略早、撞击音对准、碎屑声略晚。
- 来源：免费可商用音效库，或用代码合成（点击 = 短衰减正弦，弹出 = 上滑正弦，重击 = 下滑正弦 + 噪声，呼啸 = 加窗噪声扫频）。
- 用户只说「不要旁白」时，音效照常可以有；说「不要声音」就整条静音（或者不带音轨，看要求）。

## 5. 代码合成配乐的做法（不想做出廉价感就照这个来）

- 先定：BPM、调式、每段几个小节（前奏 / 铺垫 / 爆发 / 收尾），和 `timeline.json` 对齐。
- 分轨合成再混：底鼓（150→45 Hz 下滑正弦 + 快速衰减）、军鼓（短噪声 + 200 Hz 音）、踩镲（高通噪声，很短）、贝斯（锯齿或方波过低通，跟底鼓同步）、和弦铺底（两三个略微失谐的锯齿波 + 慢起音）、主旋律（复古电子用方波 / 三角波，轻快俏皮可以加琶音）。
- 让它不廉价的关键：包络（起音、衰减）别是硬开关；每轨音量平衡；给和弦和主旋律加一点混响（指数衰减噪声卷积，混入 15–25%）；底鼓响时把其他轨压低一点（侧链）；最后过压缩和限幅。
- 「低沉鼓点、预告片式」：大鼓（很低的下滑正弦 + 长尾混响）+ 少量金属打击，几乎没有旋律。
- 合成完先用 `beats.py` 测一遍，确认 BPM 和高潮位置和计划一致。

## 6. 混音和合成

- 用 ffmpeg：每轨用 `adelay` 放到位置、`volume` 调平衡；有旁白时配乐压低（旁白时段配乐降 8–10 dB，可以用 `sidechaincompress`）；`amix=normalize=0` 混合。
- 最后做两遍 `loudnorm` 到 -14 LUFS（真峰值 -1.5 dB）；纯旁白的片子 -16 LUFS 也可以。
- 音频长度要等于视频长度（不够补静音，多了裁掉并淡出）。
- 合成：`ffmpeg -i video.mp4 -i mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -movflags +faststart 成片.mp4`。
