# 写提示词与复刻（用户给参考视频、要复刻、要你写提示词时）

两种情况会用到：
- 用户给一条参考视频，说「做一条这样的」→ 先反推出关键因素，写成导演单，再按 SKILL.md 的流程做。
- 用户要你「写一段能做出这条视频的提示词」→ 按第 3 节的写法交一段提示词。

## 1. 从参考视频里找关键因素

**关键因素**：不写它，模型就会默认做成别的样子，而且观众一眼看得出差别。两个条件都满足才写。

| 类别 | 怎么从成片里找 |
|---|---|
| 实现路径 | 几何干净、文字锐利 → 纯代码；真实光影、景深、材质 → 三维；角色转了角度体积还一致、有轮廓光 → 三维（卡通渲染会装成 2D）；画风细腻但角色在镜头之间有细微走样 → 先生图；形变、闪烁 → 生视频；真实噪点 → 实拍 |
| 风格 | 挑代表画面，看主色、字体、线条、材质、光影，对到一个有名字的风格（见 `07-风格卡.md`），用质感词说（木刻版画、水粉蜡笔、撕纸拼贴） |
| 音乐与卡点 | `scripts/beats.py` 测节拍，算换镜头落在拍点上的比例；有没有配乐看句间静音比例（旁白片句间彻底静音 = 没有垫乐） |
| 配音 | 有没有旁白；男声女声、浑厚清亮这一层 |
| 节奏结构 | 加速冲向高潮、急停留白、一拍一卡、开头静几秒——**看到明显的节奏设计就写**，这类多半是人写进提示词的 |
| 题材和核心 | 讲的是什么、谁出场、反转是什么、最要紧的那个意思 |
| 素材 | 画面里的真实界面、照片、知名角色、歌 |
| 规格 | 横竖版、大概多长 |

**不要写的**：具体的小创意（某个象征物、角色的小表情、故事细节、日期翻页这类画面设计）多半是模型自己加的，写了反而限死它；音效、歌名这类听不准的不写；画面里「证明是代码做的」角标、代码浮窗不写。

## 2. 粒度：只写到「有没有、对不对」

| 类别 | 写到这层就够 | 写过头了 |
|---|---|---|
| 配音 | 浑厚男声旁白 | 浑厚中年男人、略带沙哑、语速 1.1 倍 |
| 卡点 | 画面切换卡在节拍上 | 128 BPM，每 4 拍切一镜 |
| 风格 | 中国奇谭那种手绘动画质感 | 主色 #C8102E、描边 2px |
| 实现路径 | 用 Blender 建模加渲染 | Cycles 渲染 128 次采样 |
| 规格 | 竖版，1 分钟左右 | 1440×1800、H.264 |

例外：用户自己写的参数（120BPM、1080p、静 3 秒）是他真想要的，原样保留。

## 3. 提示词的写法：像人在聊天框里打字

- 短句、口语，**一行说一件事，用句号断开**。不用分号，不用箭头，不堆比喻，不写一口气到底的长句。
- 不用【风格】【做法】这类标签。常用开头：「重点描绘：」「风格：」「配乐用……」，结尾一句「其他可以自由发挥。」
- 工具名可以写（Blender、Three.js、某家语音合成）；用到本机软件就加一句「先检查电脑里有没有装 Blender，没有的话帮我装好。」收费软件写「没有就告诉我」。
- **代码块里只放提示词本身**。「换成你的故事」这类说明放在代码块外面。
- 分两段交付：
  1. **完整提示词**：带上这条的具体内容。
  2. **想套用**：「风格提示词（固定，直接复制）」+「你的内容（填空，一句话）」。风格段放做法、风格、声音这些换题材也不变的东西。

样板：

```
做一条 1 分钟左右的历史讲解视频，讲四渡赤水的第一渡：土城战役。
重点描绘：我方势力和敌方势力在地图上的军队走向（势力标记上真实照片），现场复原图、山形地势图交叉。其他可以自由发挥。
男声用 gemini 3.8 TTS 来配音，浑厚男声旁白。
风格：泛黄军事地图、复古战役地图纪录片风格。
```

## 4. 有真实提示词时

以真实提示词为底，**一字不改**，只在后面补「成片里有、原文没写、不写容易做偏」的几句（比如成片有全程旁白但原文没提）。补了什么、为什么补，写在内部工作稿里。

## 5. 交给读者的内容口气要干脆

- 交给用户的提示词和说明里，只放确定的东西：不写「可能」「大概」「原文没写」「看成片还原的」「不保证一模一样」这类话。能确定的就肯定地写，不确定的就不写。
- 反推依据、把握程度、哪句是补的，只放进内部工作稿（比如 `docs/反推依据.md`），不进成品。
