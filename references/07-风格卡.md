# 风格卡：把一个风格名翻译成看得见的元素

用户给的风格词，先对到下面最接近的一张卡；对不上就照同样的格式自己写一张，写进导演单。
每张卡：**一句定义（有什么、没有什么）→ 元素清单 → 怎么做 → 容易做偏的地方。**

---

### 1. 手绘墨线卡通短片
- 定义：像手绘动画短片，有粗细变化的毛笔墨线、分层明暗和纸纹笔触；不是干净的扁平矢量。
- 元素：暖色纸底；黑褐色墨线（粗细变化、偶有飞白）；平涂 + 一两档阴影色；四周一圈深色撕纸边框；胶片颗粒和暗角；Q 版角色（头大身小）。
- 做法：Canvas 画角色和场景；墨线按速度改线宽；纸纹和颗粒叠最上层；边框是带锯齿的多边形遮罩。
- 做偏：线宽一致、没有纸纹，就成了网页插画；角色每个镜头长得不一样。

### 2. 三渲二日式动画（赛璐璐感）
- 定义：三维模型渲染成手绘动画的样子：硬边明暗、描边、轮廓光；角色转身时体积一致。
- 元素：两到三档硬阴影；黑色描边；高饱和主色；进化、亮相时的光效、速度线、发光数据空间。
- 做法：Blender 卡通材质 + Freestyle 或反向外壳描边（见 `03-路线-三维.md`）；Three.js 用 MeshToonMaterial + 外壳描边。
- 做偏：用 2D 平面图形假装，一转角度就穿帮；描边太细看不见。

### 3. 复古战役地图纪录片
- 定义：摊在木桌上的泛黄军用地图当主线，红铅笔现场画行军路线，人物用老照片头像卡出场，穿插带颗粒的复古插画场景。
- 元素：泛黄纸、等高线、比例尺、指北针、红蓝箭头、印章、电报纸条；暖光、颗粒；老照片调成棕褐色；字体用宋体或仿宋。
- 做法：SVG 路线按 t 画出；地图关键处可以用 Three.js 立成沙盘；照片卡片圆框描边；纸张有折痕和阴影。
- 做偏：做成干净的现代信息图地图；路线一下子整条出现；照片和年代对不上。

### 4. 撕纸拼贴绘本风
- 定义：像彩色手工纸剪下来一层层贴上去，纸边带白色撕边，有纸张纤维和投影；不是扁平矢量插画。
- 元素：高饱和的纸色块；每块纸外圈 6–10 像素白色锯齿撕边；轻微投影；纸纤维纹理；圆头 Q 版小人；太阳、云、海浪都有小表情。
- 做法：每个形状 = 锯齿多边形 + 白边 + 投影 + 纸纹贴图；动画像纸片被拉动（轻微旋转、弹跳）。
- 做偏：没有白色撕边和纸纹，就成了普通矢量卡通。

### 5. 动态排版产品宣传片
- 定义：超大粗黑体短句一句句砸出来，纯色大底快切，中间穿插产品真界面卡片和操作演示，结尾落版 logo 和安装命令。
- 元素：品牌主色 / 米白 / 纯黑三种大底轮换；粗黑体（句尾可以带品牌色圆点）；斜飞入的界面卡片；可见的鼠标点选、打字。
- 做法：DOM 文字逐词遮罩升起；界面用真截图（见 `04-路线-素材.md`）；切换卡拍点。
- 做偏：居中小字配渐变；界面是编的；节奏拖沓。

### 6. 《中国奇谭》式国风手绘动画
- 定义：像手绘的国风动画电影画面：颜料笔触、粗细不匀的墨线勾边、水彩纸纹理，颜色素雅偏灰。
- 元素：低饱和的青绿、赭石、墨色；云雾层次；老树、远山、小桥流水这类意境物；留白。
- 做法：Blender 三渲二 + 纸纹后期（见 03），或 Canvas 分层绘制 + 笔触纹理；季节变化用色调和天气粒子（花瓣、落叶、雪）。
- 做偏：颜色太鲜艳、太干净；变成三维游戏画面。

### 7. 2.5D 等轴科技插画
- 定义：等轴视角的积木小世界，天蓝底，蓝紫色积木，穿白大褂的扁平小人在上面演示道理；画面上字很少。
- 元素：天蓝或浅色底；蓝、紫、青的积木（每块三个面三档明度）；扁平小人（几何块拼成）；连线、光点、小图标。
- 做法：Canvas 等轴投影（见 `02-路线-网页代码.md`）；道理靠积木搭建、拆开、连线、发光演出来；换段时让一群积木飞过画面。
- 做偏：把要点写成大段文字；积木画成带真实光影的三维；小人僵着不动。

### 8. 科技蓝玻璃拟态界面
- 定义：深蓝科技底上的半透明毛玻璃卡片、发光细线和标签，一镜到底，讲到哪个词就点亮哪个东西。
- 元素：深蓝渐变底 + 细网格；毛玻璃卡片（模糊 + 白色细边 + 高光）；青色发光线；数据标签。
- 做法：DOM + CSS backdrop-filter（逐帧渲染没问题）；元素按旁白时间点亮。
- 做偏：发光过度、到处霓虹；卡片同时出现。

### 9. 特工战术 HUD
- 定义：写实照片上叠战术界面：取景框、时钟、心率、测距线、目标锁定框，配一本正经的大字。
- 元素：写实照片素材（生图，见 04）；绿色或琥珀色单色 HUD 线条；等宽数字（逐帧跳动）；扫描线、闪烁；中文粗黑大字。
- 做法：照片推拉 + 视差；HUD 全部代码画；数据每帧按 t 变化；切换卡拍点。
- 做偏：让生图把字和界面画进照片里（会乱码）；猫每个镜头长得不一样。

### 10. 三维白模说明书（宜家风）
- 定义：全程白模加细描边，每一步新加的零件用橙色高亮、从外面飞进来装到位，最后一步整体上色。
- 元素：白色模型、细黑描边、浅灰底；橙色高亮；步骤编号和一句说明；简洁的「下一步」按钮。
- 做法：Three.js（见 03-A）；相机每步转到新零件，最后绕成品一圈。
- 做偏：一开始就是彩色；零件直接出现、不飞入；镜头不动看不清新零件。

### 11. 深色科技发布会风（口播视频包装）
- 定义：黑底配荧光黄绿点睛，口播人像在全屏、小窗之间切换，讲概念时整屏换成解释动画，放案例时全屏。
- 元素：纯黑底；荧光黄绿（或品牌色）强调；便利贴、贴纸式标签；全程字幕。
- 做法：口播视频当主轨，代码动画做叠层和解释段；贴纸跟着口播的词逐个弹出。
- 做偏：全程小窗或全程全屏；动画和口播的词对不上。

---

### 自己写风格卡时
- 风格名用标准叫法（「撕纸拼贴」「赛璐璐」「等轴插画」），不要自造词。
- 元素清单要能在静帧上逐条检查。
- 写一条「做偏」：不写清楚，模型最可能退回到什么样子。
