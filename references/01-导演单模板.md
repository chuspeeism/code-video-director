# 导演单模板（第 1 步必填，存成 `docs/导演单.md`）

用户给的往往只有一句话，缺的部分你不写，模型就会退回默认值。导演单的作用是把「做什么」补成「怎么做才对」。
填的原则：**关键因素写到能判对错的那一层**，镜头里画什么、构图、动效细节留给第 4 步，不要在这里猜细节把关键因素淹掉。

---

## A. 硬要求（逐字抄用户原话，一条一行，交付前逐条打勾）

| # | 用户原话 | 我要做到的样子（能判对错） | 交付前核对 |
|---|---|---|---|
| 1 | 例：「配乐用 Vexento 的《Searching Robot》，截主歌到副歌」 | 用给的音频文件；从主歌安静段开始，副歌第一拍对准猫变身 | ☐ |
| 2 | 例：「不要旁白，台词用字幕和对话气泡」 | 音轨里没有人声；台词全部是画面上的字 | ☐ |
| … | | | |

用户点名的歌、工具、风格、时长、横竖版、有无旁白配乐，**全部**进这张表。

## B. 关键因素（每项一两句）

1. **实现路径**：纯网页代码 / Three.js / Blender / 先生图再用代码包装 / 交互网页录屏 / 调用本地软件。写出为什么（哪句原话决定的）。
2. **风格**：给一个**有名字的风格**（见 `07-风格卡.md`），再写「看得见的元素清单」：
   - 色板（3–5 个颜色，写出用途：底色、主体、点缀）
   - 线条（毛笔墨线 / 细描边 / 无描边）
   - 材质和纹理（纸纹、颗粒、撕边、玻璃、颜料笔触）
   - 光（平光 / 侧光投影 / 轮廓光）
   - 字体气质（毛笔字 / 粗黑体 / 等宽 / 手写）
   - **不许出现的**（例：不要渐变底、不要霓虹、不要居中大字开场）
3. **声音**：有没有配乐、配乐从哪来（给的文件 / 免费曲库 / 代码合成）、什么感觉；卡不卡点、哪一刻对哪一拍；有没有旁白、男声女声、浑厚还是清亮；有没有音效。
4. **规格**：横竖版、分辨率、帧率、大概时长。
5. **内容核心**：一两句话。故事写出反转；讲解写出几个要点和每个要点要让人感到的那件事；宣传片写出最重要的 3 个卖点。
6. **素材**：用户给了什么（歌、图、代码、参考图），还缺什么、打算怎么补（查公开图库、生图、代码画）。
7. **节奏档**（SKILL.md 第 14 条的表）：讲述铺陈（稳）/ 快剪（快而有呼吸）/ MV 打斗（一直热闹），选一档，或者按段分：写出每段的起止秒、哪一档、为什么（哪句原话、什么片型），以及这一档的动作用时和停顿范围。例：「0–12 秒快剪（主角日常，一下动作停一下），12 秒起 MV（进化高潮，一直热闹）」；「全片讲述铺陈：照片慢推 0.6–0.9 秒、路线一笔画出来，讲完一个点停 0.5 秒」。MV 片里的安静段（包扎、回忆、对峙）仍按 MV 档，只有片头前奏才铺陈。跑 `qa.py`、`selfcheck.py`、`lock.py` 都用这里定的档（`--style` 或 `--sections`）。

## C. 导演层（让片子「高级」的部分）

1. **观众先看哪**：每一段的主体是谁，次主体是谁，背景做什么（背景可以有极轻的流动，但原地晃不算动作）。
2. **层次**：前景（偶尔掠过、补层次）、中景（主事件）、远景（气氛）；平面排版就用上中下三层。
3. **运动语言**：重要动作写成「预备 → 加速 → 冲击 → 压扁 / 过冲 → 回稳 → 余波」；主体先动，阴影、相机、文字晚几帧（错相）。
3b. **动态方案**（每个镜头一行，见 SKILL.md 第 14 条）：主动作从哪到哪、用时（按节奏档：讲述档的稳动作 0.5–1.0 秒、利落动作 0.25–0.4 秒；快剪、MV 档 0.2–0.5 秒）、曲线（快起慢停 / 弹出带回弹；讲述档的慢推、画线可以两头对称地慢）；同时在演的另外几样（MV 档至少两样：跟随动作、一串依次飞入或拼装的小物件；讲述档 0–1 样）；镜头这一段动不动、推完停在哪；动作之间停多久（讲述、快剪档 0.3–0.8 秒，MV 档最多 0.2 秒）。**高潮段写事件表**：每件事落在第几小节第几拍、各是什么（每 2.4 秒至少 5 件不同的事），同一类冲击一次比一次重；每个镜头写它自己的事，不许整列复制同一句。
4. **相机**：全片的相机路线（推、拉、摇、绕、跟，每段有起有停、推完停住），镜头之间怎么接（形状接形状、颜色铺满、甩镜头、遮罩擦除、物体穿过）。
5. **节奏曲线**：起势（前 2 秒要有钩子）→ 发展 → 高潮（落在音乐高潮或故事反转）→ 收束（落版停够 1.5 秒）。
6. **光**：主光方向全片统一；关键物体不能死板，高光和阴影要跟着动。
7. **声音事件**：哪些动作要有音效（落地、碰撞、切换、打字），音效打在动作接触的那一帧。

## D. 禁止项（默认全部生效，再加本片特有的）

- 不加「代码生成」之类的自证角标、代码浮窗、水印、技术参数。
- 不用渐变底配居中大字当开场；不全片淡入淡出；不用闪白遮丑。
- 字不出画、不被挡；同一时刻屏幕上的大字不超过一句。
- 不编造数字、论文、人名；不画假的产品界面。
- 不用用户没给、又有版权的音乐、图片、人物照片（给了的除外）。
- 本片特有：……

## E. 验收标准（能被机器或一眼核对）

- 时长 X 秒 ± 10%，分辨率 W×H，帧率 F。
- 硬要求表 A 全部打勾。
- `qa.py`：无黑帧、无 >1.5 秒冻结（片尾除外）、响度 -16 到 -12 LUFS；卡点片切点落拍比例明显高于随机；无配乐的片子句间是真静音；动态十项（动作快不快、快动作够不够、快起慢停、慢起慢停、动作用时、原地晃动、镜头在动、动作有长有短、起步有加速、画面在重播）按 B7 的节奏档（`--style` / `--sections`）全过；`selfcheck.py` 的返工单清空（含「分镜动作复制」）；逐帧条上同屏至少 3 样在演。
- 评分表 10 项都 ≥ 8 分。
