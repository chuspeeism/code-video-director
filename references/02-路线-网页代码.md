# 路线：网页代码逐帧渲染（DOM + Canvas / SVG）

适用：绘本、手绘卡通、信息图、动态排版、地图、科普插画、产品宣传片的大部分画面。三维部分见 `03-路线-三维.md`。

## 1. 引擎规矩（违反任何一条，返工就会牵一发动全身）

- 一个 `index.html`，定义 `window.seek = async (t) => { … }`，**所有样式和绘制只由 t 算出来**。没有定时器、没有 CSS transition / animation、没有「上一帧的状态」。
- 资源（字体、图片、音频波形数据）全部加载完再设 `window.ready = true`；字体用 `await document.fonts.ready`，图片用 `await img.decode()`。
- 随机用带种子的 `mulberry32(seed)`，并且**在 seek 外面预先生成好**（比如 200 个粒子的位置），seek 里只读不改。
- 常量、分镜时间表放在文件最前面：`const SHOTS = [{id:'s1', a:0, b:3.2}, …]`，`seek` 里先找当前镜头，再画。镜头的起止时间从 `timeline.json` 读，和声音的节拍对齐。
- 从 `templates/engine.html` 起步：`seg(t,a,b)` 取区间进度、缓动函数、`spring()` 弹簧、相机、逐词升起的文字都现成。
- 尺寸：舞台固定成成片分辨率（1920×1080 或 1080×1920），所有坐标按这个写，不要响应式。
- 中文字体：先用系统字体（macOS：PingFang SC、Songti SC、Kaiti SC、Hiragino Sans GB；Windows：Microsoft YaHei、SimSun、KaiTi）。要毛笔字、手写体时，可以下载开源字体（思源黑体 / 思源宋体、站酷快乐体、马善政毛笔楷书等 OFL 字体，Google Fonts 上都有），**放进工作目录本地加载**，不要依赖网络字体。

## 2. 质感层：让「代码画的」不显得廉价

代码画的东西廉价，通常是因为只有形状没有质感。下面这些层叠上去，观感会差很多：

| 质感 | 做法 |
|---|---|
| 纸纹 | 预先生成一张 1920×1080 的噪声纹理（两三层不同尺度的值噪声 + 稀疏的短纤维线），`multiply` 叠在最上层，透明度 0.15–0.35 |
| 撕纸边 | 多边形边缘用带种子的随机锯齿（每 6–12 像素一个点，振幅 3–8 像素），外面再描一圈 6–10 像素的白边并加一点投影 |
| 毛笔墨线 | 沿路径按速度改线宽（起笔细、中段粗、收笔细），每段加 ±0.6 像素的抖动，偶尔留飞白（把线宽在小段上降到 0.3） |
| 颗粒 / 胶片 | 每帧用 `mulberry32(frameIndex)` 撒细颗粒（这样仍然是确定的），加暗角 |
| 颜料笔触 | 大色块里叠几十条半透明的同色系短笔触，方向一致，随场景慢慢漂移 |
| 投影和体积 | 平面图形加一层偏移的深色投影，或者在边上加一条亮边（轮廓光） |
| 等轴 2.5D | 用等轴投影 `x' = (x - y)·cos30°，y' = (x + y)·sin30° - z`，每个方块画顶、左、右三个面，三个面用同一色相的三档明度 |

**风格要求里提到的每一种质感，都要在静帧上看得到。** 静帧自查时把画面缩小到 360 宽再看一遍：质感在小图上还认得出，才算做到位。

## 2b. 构图：别做成网页

网页代码画视频，最容易带出「做网页」的习惯。逐条避开：
- 不要标签页、导航条、页码、面包屑、「01/07」步骤号、页眉页脚日期戳。
- 不要「左边标题 + 右边一张小图」的固定版式，每个镜头换构图（见 `06-运动与镜头.md` 的景别表）。
- 主体至少占画面高度的 1/3，画面铺满场景；颜色按风格给足饱和度和对比度，别默认浅灰淡蓝。
- 讲解片的道理要靠角色和物体的动作演出来：说「把概念变成物体」，就让小人把一块积木推进机器；说「连线」，就让线一条条画出来连上。一个要点配一个看得懂的动作，而不是一个大数字。
- 数字可以出现，但要「长」出来（滚动计数、柱子生长），并且和画面里的动作在同一个镜头里发生。

## 3. 角色（代码画人物时）

- 每个角色写成一个绘制函数 `drawHero(ctx, {x, y, scale, pose, face, t})`，所有镜头都调用它，保证造型统一；表情、手臂角度、身体倾斜做成参数。
- 至少准备 4–6 种姿态（站、走、跑、挥剑、惊讶、倒下），用参数插值过渡，不要整张图平移。
- 眨眼、呼吸、衣角摆动这种小动作一直开着（用正弦和 t 算），角色就不会像贴纸。
- 群战场面：同一个怪物函数 + 不同参数（颜色、大小、动作相位）铺开，数量要多，层次要分前后。
- 精细人物（知名角色、写实人物）代码画不像，优先走三维或生图（见 SKILL.md 第三节）。

## 4. 文字

- 字幕：底部居中，最多两行，单行不超过 16 个汉字；黑色半透明底条或描边，确保在任何画面上都读得清。停留时间 ≥ 字数 × 0.25 秒 + 0.5 秒。
- 大字（标题、金句）：逐词或逐字遮罩升起（`translateY(105%)` 在 `overflow:hidden` 里升上来，每个词错开 40–60 毫秒），重点词换颜色或加粗；**同一时刻屏幕上只有一句大字**。
- 对话气泡：气泡先弹出（弹簧，过冲一点），字再逐字出现；气泡尾巴指向说话的人。
- 所有字离画面边缘至少 6%（安全区）。

## 5. 地图、路线、数据

- 路线：SVG 路径用 `stroke-dasharray` / `stroke-dashoffset` 按 t 画出来；箭头跟着路径头走；路线画完以后，沿线标注再一个个弹出。
- 势力或军队标记：圆形徽章（真实照片或头像裁圆 + 颜色描边），沿路线移动时带一点惯性。
- 山形地势：等高线（多层同心不规则闭合线）加侧光阴影；要真立体就交给 Three.js（见 03）。
- 数字：从 0 滚到目标值（缓动），单位小一号；图表元素逐个生长，不要一起出现。

## 6. 性能

- 1920×1080、30 帧，60 秒就是 1800 帧。单帧渲染控制在 0.3 秒内：大面积纹理预先画进离屏 canvas，每帧只贴图；粒子数量控制在几千以内。
- `render.mjs --workers 4` 并行渲染；只改了某几秒，就只删掉那段帧重渲。
- 帧图默认存在 `out/frames.noindex/`：文件夹名以 `.noindex` 结尾，macOS 的 Spotlight 就不会去索引成千上万张帧（索引会占满好几个核、拖慢整机）。自己写渲染脚本时也这样命名。同时跑好几条片子时，`--workers` 合计别超过 CPU 核数。
- 在别人正在用的电脑上（或者同时跑好几条片子），渲染、转码、解码大视频这类重活用低优先级跑：命令前加 `nice -n 19`（macOS 再加 `taskpolicy -b`），一次只跑一个重活，开之前看一眼 `uptime`，负载已经很高就先等等。机器卡死，用户连鼠标都动不了。

## 7. 常见坑

- 缓动函数两端要精确返回 0 和 1，否则 `if (p > 0)` 这类判断会让元素提前冒出来。
- 被隐藏的父元素下，子元素用 `visibility: inherit`，别写死 `visible`。
- 每个图层写明 `z-index`。
- 相机缩放时测量文字宽度用 canvas 的 `measureText`，不要用 DOM 尺寸。
- 缩放过的模糊文字不要再放大，交接时只淡变填充色。
