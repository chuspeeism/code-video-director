# 路线：三维（Three.js / Blender / 交互网页录屏）

先判断要不要三维：**物体要转着看、沙盘要立起来、角色转身后体积要一致、组装要看清前后关系**，就要真三维。平面画法装不出这些。

## A. 网页里的 Three.js（照样走 seek(t)）

- 不用 `renderer.setAnimationLoop` / `requestAnimationFrame`。在 `window.seek(t)` 里：按 t 算出相机位置、物体变换、材质参数，然后 `renderer.render(scene, camera)` 一次。
- `new THREE.WebGLRenderer({ antialias: true, preserveDrawingBuffer: true })`，像素比固定 1，尺寸等于成片分辨率。
- 模型、贴图、字体全部加载完再 `window.ready = true`。Three.js 用本地文件（`npm i three`，用 import map 指到 `node_modules/three/build/three.module.js`），不依赖 CDN。
- 动画只写成 t 的函数：位置用缓动或弹簧插值，相机沿样条曲线（`CatmullRomCurve3`）按 t 取点，`lookAt` 的目标也插值。
- 风格要靠材质和后期：
  - 白模说明书风：`MeshStandardMaterial` 白色、粗糙度高；描边用 `EdgesGeometry` + `LineSegments`（阈值 20–30°）；环境光 + 一盏投影主光。新零件用高亮色（如橙色）材质，到位后再慢慢变回白或上色。
  - 沙盘 / 地形：平面网格按高度图位移，顶点颜色按高度分档，侧光打出起伏；路线用贴着地形的管线或贴花。
  - 卡通渲染：`MeshToonMaterial` + 3–4 档的渐变贴图，加反向外壳描边（把模型沿法线放大 2–3%，只渲背面，纯黑）。
- 组装类：每个零件记住「最终位置」和「飞入起点」，第 k 步时第 k 个零件从起点沿弧线飞到终点（预备 → 加速 → 落位过冲 → 回稳），落位瞬间可以加一个小的缩放弹跳和一圈高亮。相机每步转到能看清新零件的角度。
- 渲染：和网页路线一样用 `scripts/render.mjs`。WebGL 慢的话降低阴影贴图尺寸，或者 `--workers 2`（多开太多页面会抢 GPU）。

## B. Blender（点名 Blender、三渲二、角色要立体时）

1. **装和找**：先 `which blender`；macOS 常见路径 `/Applications/Blender.app/Contents/MacOS/Blender`。没有就装（macOS 可以 `brew install --cask blender`）。
2. **全部用 Python 脚本驱动**，后台渲染：`blender -b -P build_scene.py -- --out frames.noindex/`（图片序列放进 `.noindex` 结尾的文件夹，避免 macOS Spotlight 索引拖慢整机）。不要手点界面。脚本分三段：建场景 / 导入模型 → 打关键帧（按 `timeline.json` 的秒数换算帧号）→ 设置渲染并输出图片序列。
3. **模型**：
   - 优先免费可商用的现成模型（Sketchfab 的 CC 授权模型、Poly Haven、Kenney 等），格式用 glTF / GLB / FBX / OBJ，`bpy.ops.import_scene.gltf(filepath=…)` 导入。
   - 需要登录才能下载的，无人值守时拿不到：换成能直接下载的同类模型，或者用 Blender 几何体自己搭简化造型，**在交付说明里写清楚**。
   - 知名角色：找粉丝做的免费模型，交付说明里写明来源和授权；找不到就做「剪影 + 标志特征」的简化造型，不要硬凑。
3b. **导入模型的三条硬规矩**（静帧自查时逐条看）：
   - **不许出现 T 型 / A 型姿势**（建模默认的张开双臂）。模型带动作就用自带动作；不带就旋转骨骼摆出姿势（站姿、蓄力、咆哮、出拳），至少每个镜头一个姿势。
   - **材质全部换掉**：导入的模型自带写实或默认材质，要三渲二就逐个换成下面第 4 条的卡通材质加描边，静帧上能看到硬边明暗和黑色描边才算换好。
   - **三维的价值在机位**：每个镜头换机位（低角度仰拍亮相、推近到脸、绕着角色转、从背后越过肩膀），镜头里也要动。全程一个正面固定机位，等于白做了三维。
4. **三渲二（卡通渲染）**：
   - 材质：Shader to RGB → ColorRamp（插值设 Constant，3 档明暗）→ 输出；或用 Toon BSDF。
   - 描边：开 Freestyle（线宽 1.5–3 像素），或给物体加 Solidify 修改器做反向外壳（翻转法线 + 只渲背面 + 纯黑材质）。
   - 渲染器：EEVEE（快），分辨率按成片设，采样 16–32 就够；色彩管理用 Standard，不要 Filmic / AgX 把颜色洗灰。
5. **手绘 / 国风质感**（如《中国奇谭》式）：参考图只学画风。用纸纹贴图做世界背景或后期叠加；颜色压低饱和、偏灰；墨线描边加粗细变化；渲染完用合成节点或 ffmpeg 叠纸纹和轻微颗粒。
6. **相机一直在动**：每个镜头至少有推、摇、绕中的一种运动；进化、变身、亮相这种高潮镜头用快速推进加一点镜头抖动。转场可以在合成阶段用 ffmpeg `xfade`（擦除、径向、像素化），也可以在场景里做（物体穿过镜头、光爆遮挡）。
6b. **高潮镜头**（进化、变身、亮相）：光爆、粒子、速度线、冲击波这类 2D 特效用网页 seek(t) 渲成透明 PNG 序列叠在三维画面上；角色名做成大字标题卡（粗字、描边、斜切入场），停够 1.5 秒；切换踩在节拍上（用 `scripts/beat_timeline.py`）。
7. **合成**：图片序列 → ffmpeg 出视频，再和音频合成。大字、标题、字幕这类 2D 叠层，用网页 seek(t) 渲成透明 PNG 序列再叠上去，比在 Blender 里做文字好控制。
8. **时间**：Blender 渲染慢，先渲每个镜头的一帧做静帧自查，再全片渲染；全片渲染放后台跑，记好进度，中断后从断点继续（`scene.frame_start` 设成已渲到的帧）。渲染用低优先级：`nice -n 19 blender -b …`（macOS 再加 `taskpolicy -b`），别把用户的电脑卡死。

## C. 交互网页 + 录屏（「可以自己点的网页」「录一段操作」）

- 先把网页做成真的能交互：按钮、步骤状态、相机过渡都用真实交互逻辑实现，人手点也能用。
- 录视频时用 Playwright 驱动：一个固定尺寸的页面，脚本按时间表模拟鼠标移动和点击。**鼠标要看得见**：页面里加一个跟随鼠标的光标元素，点击时有一圈涟漪。
- 为了画面稳定，录制版也让页面支持 `window.seek(t)` 或者「第 k 步的第 p 进度」这种可定位状态，用 `render.mjs` 逐帧渲染；实在只能实时录，就用 Playwright 的 `recordVideo`，录完用 ffmpeg 修剪、转码。
- **不占用真实屏幕和鼠标**：不开有界面的全屏浏览器，不用系统录屏工具，不移动真实鼠标，也不申请屏幕录制权限。这些做法会和用户、和别的程序抢屏幕，还会弹出系统授权框把任务卡住。全部在无头浏览器里完成，光标是页面里画出来的元素。
- 每一步的停留时间要够看清：新零件飞入完成后至少停 1 秒再点下一步。
- 竖版就把页面尺寸设成 1080×1920，按钮放在下方三分之一，避开上下安全区。
